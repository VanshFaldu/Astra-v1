Structural analysis conventions
Complexity starts at one and adds decisions: if, loops, exception handlers, conditional expressions, boolean alternatives, comprehension decisions and non-default match cases. Nested function and class bodies are measured independently. LOC is the source span, including comments and blank lines.
Duplicate detection compares exact AST function bodies of at least three statements, ignoring formatting and locations. It does not rename identifiers. Unused-local detection is lexical; it does not prove dead code or track values through control flow.

Evidence before accuracy.
A transparent decision tree, independent labels, and repository-separated evaluation.
TRAINING WORKFLOW INCLUDED
No trained model loaded
Rule-based analysis is fully available. We do not present threshold-generated labels as independent AI evidence.
01 / Prepare reviewed data
Extract function metrics, then have reviewers label maintainability independently of the configured rules. Record repository and review rationale. Use at least 30 functions across 5 repositories for the training script; this minimum is a software guard, not evidence of statistical adequacy.
02 / Train & evaluate
Run py ml.py dataset.csv in the project folder. The script holds out entire repositories and reports precision, recall, F1 and the confusion matrix. Refresh and analyze to load the resulting model.
Predictions represent leaf class proportions, not calibrated confidence. The binary target is “function requires review,” not a specific smell category.
Comparative experiment
Evaluate rules, the model, and a predefined hybrid policy against the same independent held-out labels. Keep repository groups separate, tune only on training data, and report class support. No benchmark score is claimed before that experiment is completed.

What makes this a CD project?
Lexical analysis produces tokens. Syntax analysis constructs a Python AST. Scope inspection identifies local bindings. Tree visitors derive structural metrics. A static analysis pass emits source-mapped diagnostics.
Python supplies the lexer and parser; this project implements the analysis passes. It does not implement code generation or a complete optimizing compiler.

Viva essentials
Why AST instead of raw text?
The AST captures program structure and ignores formatting. A string containing “if” does not become a branch, while an actual conditional becomes an If node.
What does ML add?
A model can learn interactions between reviewed metrics. It must earn that claim through independent labels and held-out evaluation; relearning rule-generated labels is not evidence of improved detection.
What are the limitations?
Single-file Python analysis, heuristic thresholds, lexical unused-variable checks, exact-body duplication, no interprocedural control-flow analysis, and dataset-dependent ML performance. A finding is a review prompt, not a proven defect.
